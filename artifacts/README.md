# Artifacts

Generated tables, figures, model outputs, and QA reports live here locally. Large/generated files are ignored by default.

For any artifact cited in the manuscript, record in `EXPERIMENTS.md`: generating script, input dataset/checksum, output path, date, and commit SHA.

Small finalized QA Markdown summaries and compact result tables/metadata that are necessary for audit/recovery may be committed intentionally. Raw data, large model objects, and bulky generated outputs remain local unless explicitly approved for release.
