# NEXT EXPERIMENT — REPRO-PIPELINE-01

Priority: P0
Gate: G2 Reproducible pipeline

## Question

Can the canonical province-year analysis dataset be rebuilt deterministically from documented inputs, with no sandbox-specific paths and with every verified correction/derived field generated by code?

## Inputs

- PCI yearly source files / current combined PCI data.
- Legacy enterprise-revenue panel as a migration input.
- `data/metadata/revenue_corrections.csv`.
- `src/eureka2026/revenue_corrections.py`.
- Existing 10-subindex panel and its structural-missingness contract.
- G1 evidence in `artifacts/qa/DATA-INTEGRITY-01.md`.

## Procedure

1. Define repository-relative input/output paths and a single command/entry point for the build.
2. Read source/migration inputs without editing them in place.
3. Normalize province names using an explicit mapping, not ad-hoc notebook replacements.
4. Apply only the three verified revenue corrections through committed code.
5. Recompute:
   - annual revenue growth;
   - PCI lag fields needed downstream;
   - any other derived modeling column from canonical source columns.
6. Join PCI/revenue/sub-index data with one-to-one province-year assertions.
7. Validate:
   - 945 unique province-year rows;
   - 63 provinces each year and 15 years each province;
   - positive revenue;
   - 100% intended merge coverage;
   - CSTP6 missing only for 2010–2012;
   - no unintended missing values;
   - no absolute `/mnt/user-data` paths in active source.
8. Emit a canonical processed CSV plus SHA-256 checksum and a QA summary.
9. Declare runtime dependencies and make CI run the deterministic unit/static checks.

## Pass criteria

- One documented command can rebuild the canonical processed dataset from identified inputs.
- Output checksum is stable on two consecutive builds with unchanged inputs/code.
- All invariant and correction tests pass.
- No active source requires `/mnt/user-data/uploads` or `/mnt/user-data/outputs`.
- Derived growth values reflect the verified revenue corrections.
- Canonical build and output schema are documented.

## Output artifacts

- canonical build script/module;
- `data/processed/panel.csv` locally (not necessarily committed if source/license policy forbids it);
- `artifacts/qa/REPRO-PIPELINE-01.md`;
- recorded output SHA-256;
- CI/test result.

## Unlocks

G3 final two-way fixed-effects baseline.
