# Anonymity and compliance checklist — Euréka 2026

Use before any final upload.

- [ ] No author names in manuscript body, cover, header/footer or appendix.
- [ ] No university/institution name.
- [ ] No institution logo.
- [ ] No supervisor/advisor name.
- [ ] No acknowledgements identifying the team.
- [ ] No email, student ID or file metadata that identifies authors.
- [ ] Survey/instrument appendices contain no identifying header.
- [ ] A4, Times New Roman 13.
- [ ] Line spacing 1.3–1.5.
- [ ] Left margin 3 cm; top/bottom/right 2 cm.
- [ ] Vietnamese or English consistently.
- [ ] Poster is portrait 0.8 m × 1.3 m.
- [ ] All quantitative statements pass `NUMBER_TO_ARTIFACT_MAP.md`.
- [ ] No causal wording unsupported by the design.
- [ ] No feature-importance plot/ranking unless G4 gate is satisfied (currently it is not).
- [ ] References resolve to primary/official sources where possible.
